# Tugas1_-Komputasi-Statistika
Tugas ini membahas mengenai struktur data dalam R, meliputi vektor numeric, integer, logical, character, matriks 4×4, data frame, array 4 dimensi, dan list. Materi ini digunakan untuk memahami berbagai jenis data serta cara menyimpan, mengelola, dan mengolah data dalam pemrograman R untuk kebutuhan statistika dan analisis data.
